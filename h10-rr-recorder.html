How to use

Once, before the first session

  1. Open this page in the free app Bluefy – Web BLE Browser (Safari cannot use Bluetooth). Bookmark it.
  2. Label the four sensors H10-01 to H10-04. The first time you tap Connect on a card, pick the sensor whose ID (printed on the sensor) matches that label. The card remembers it.
  3. Recommended: update each sensor to the latest Polar firmware (4.2.0 or later) with the Polar Flow app.
  4. Use the same iPad to start and to download a given sensor. Newer Polar firmware only lets the device that started a recording read it.

Start (per participant)

  1. Wet the electrodes, put the strap on the participant and clip the sensor on. The sensor only switches on when it touches skin.
  2. On the participant's card tap Connect. Check that a heart rate appears and “skin contact ✓”.
  3. Type the participant ID and tap Start recording. The iPad disconnects; the sensor keeps recording on its own, also far from the iPad.
  4. Use the clock at the top of this page for the timing sheet.

End (while the participant still wears the strap)

  1. Tap Connect → Stop & download. Wait until “Downloaded” appears.
  2. Tap Email data → choose Mail → send to the address shown above.
  3. Tap Clear sensor memory. Then remove the strap. The card is ready for the next participant.

Important

  • Do not unclip the sensor from the strap during a session: that stops the recording.
  • A copy of every download stays in the list above until you delete it, so you can email it again.
  • If a Bluetooth pairing request appears, tap Pair.
  • If Connect fails: make sure the strap is worn, close other apps that use the sensor (Polar Flow, Polar Beat, EphorPolar), and in iPad Settings → Bluetooth tap “Forget this device” for the Polar H10, then try again.

Pilot test (once)

Record 15 minutes. Around minute 5, lift the strap off the skin for about one minute without unclipping the sensor. Stop, download and email the data. The info file shows whether the sensor reports the offline period.
