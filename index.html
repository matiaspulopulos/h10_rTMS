How to use

Once, before the first session

  1. Open this page in the free app Bluefy – Web BLE Browser (Safari cannot use Bluetooth). Bookmark it.
  2. Label the four sensors H10-01 to H10-04. The first time you connect a card, pick the sensor whose ID (printed on the sensor) matches that label. The card remembers it.
  3. Use the same iPad for the whole session of a participant.

Start (per participant)

  1. Wet the electrodes (or use electrode gel), put the strap on and clip the sensor on.
  2. Tap Connect. Check that a heart rate appears and “skin contact ✓”.
  3. Type the participant ID and tap Start recording. The time is logged as the event “Start recording”.

During the session: one tap per event

  1. At each change of phase tap the blue event button on the card (Start TMS1, Start break1, …). The time is saved at the moment you tap.
  2. The app then checks the sensor by itself (about 10–15 s). You can go on with other work.
  3. Green: all OK, nothing to do.
    Orange: poor signal or could not connect. Adjust the strap (and check the iPad is within ~10 m), then tap Check again.
    Red: the recording had stopped. Adjust the strap, then tap Check again. The app saves what was recorded and starts a new part by itself.
  4. Repeat Check again until the card is green. Only green means: recording and good contact.
  5. Wrong button? Use Undo last event. Missed one? Use Other event… right away.

End (while the participant still wears the strap)

  1. Tap Stop recording and confirm. Wait until “Stopped and saved” appears.
  2. Tap Save files. One zip file with all data of this participant is saved (Downloads / Files app). Send it to Matias.
  3. Tap Clear sensor memory. Then remove the strap. The card is ready for the next participant.

Important

  • Do not unclip the sensor from the strap during a session: that stops the recording.
  • A copy of every recording stays in the list above until you delete it, so you can save it again.
  • If a Bluetooth pairing request appears, tap Pair.
  • If the page was reloaded, the first tap on a card may ask you to pick the sensor again: pick the one with the matching ID.
